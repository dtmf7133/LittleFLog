# LittleFlog

Hello and welcome to LittleFLog!<br>
	  
LittleFLog is a light, simple, software on premise to build and own small free log.<br>
	   
LittleFLog is released under GPLv3 license, it is supplied AS-IS and we do not take any responsibility for its misusage.<br>
	   
First step, go in the config file and set all the necessary values:<br>
	   
<ol>
<li>Check the write permissions of your "data" folder in your web app Private path; and set its path in the config file.</li>
<li>Set APP_DATA_PATH.</li>
<li>Set APP_PAGETITLE.</li>
<li>Set APP_PAGEDESC.</li>
<li>Set APP_PAGEKEYWORDS.</li>
</ol> 

You can access the single log page by http://yoursitename.xyz/?what=%page%.<br>
